Alzheimer System Prediction

What is Alzheimer?

Alzheimer’s disease is a progressive neurological disorder that affects the brain, causing problems with memory, thinking, and behavior. It is the most common cause of dementia, a general term for memory loss and other cognitive abilities serious enough to interfere with daily life.

Why detection is needed?

Early assessment can help people access care, plan for the future, and find support for themselves and their caregivers. A qualified clinician must assess symptoms and determine a diagnosis.

The aim of this project

This project explores Alzheimer-related classification using MRI images and structured clinical information. It presents two saved model workflows in an interactive application for coursework demonstrations.

This indicates whether the genotype has been imputed. Imputation estimates unobserved genotypes from observed data.
